The Critic's Value Network

A simplified view of how the critic looks at a partially built building and predicts its final score — the number every placement is rewarded against. The real model is a set-transformer over hundreds of candidate placements; this is the picture for a first read.

input to the critic reward coefficient (incentive) penalty coefficient (cost) hidden neuron (unnamed)
Inputs

Four things the critic can see at any step: the neighborhood's urban context, the building's state so far, the set of candidate placements, and the module vocabulary it can reuse.

Reward terms

Positively weighted design goals — how much of the site is filled, how rentable the floor plan is, how much daylight rooms get, and how well modules are reused across floors.

Penalty terms

Negatively weighted costs — broken topology, an under-filled site, uneven room sizes, and deep interior rooms trapped away from the facade.
